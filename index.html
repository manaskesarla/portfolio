01 · Featured case study

NovaLIMS

Co-founder · live with a laboratory client

A multi-tenant SaaS that runs an environmental laboratory from sample collection to invoice. I did the field research, built the product and set up how it runs in production.

1 · Field research

Discovery

  • I visited the office of an environmental testing laboratory in India and interviewed 13 employees, about 30 minutes each, across their roles. I also spoke with the founder.
  • I mapped the whole workflow end to end: customer request, sample collection, testing, review, reporting and invoicing.
  • I wrote down the problems each person faced in their own work, then turned them directly into features.

Problem heard, feature built

  • Keeping quotes, purchase orders and invoices in stepQuotes, purchase orders and invoices reconciled
  • Checking work before a report goes outQuality checks before reports go out
  • Getting notes written downStaff dictate notes by voice

2 · What I built

Product

A multi-tenant SaaS for environmental laboratories: sample lifecycle, quotes, work orders, certificates, billing and a customer portal. I co-founded it and built the backend, the web app and the marketing site.

  • PostgreSQL row-level security isolates each lab's data.
  • Role-based access.
  • A hash-chained audit trail.
  • Whisper speech-to-text dictation.
  • An LLM turns plain-English questions into SQL, checked so it can only read.

Live at novalims.in with a laboratory client.

3 · How it runs

Deployment

I set all of this up by hand.

  • AWS Amplify for hosting.
  • AWS EC2 for the API server, behind Nginx and managed with systemd.
  • PostgreSQL installed directly on the server, not RDS.
  • An S3 bucket for file storage, created with AWS CloudFormation.
  • Email through AWS SES.
  • Automated testing and deploys with GitHub Actions.

FastAPI · PostgreSQL · React · TypeScript · Astro · AWS (Amplify, EC2, S3, CloudFormation, SES) · Whisper · GitHub Actions

04

Microplastics from FTIR spectra

An ML pipeline that names the polymer in a particle from its infrared spectrum, with calibrated confidence and an "unidentified" option.

  • 6,256 spectra, 8 classes, PCA + SVM, split by particle to avoid leakage.
  • 87.7% accuracy and 0.873 macro-F1 on held-out particles.

Python · scikit-learn · SVM · PCA
